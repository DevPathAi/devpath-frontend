# design-sync notes — Leva Design Tokens

- **Shape**: off-script, tokens-only. The product UI is Flutter (`packages/dp_design`), so there is no React `dist/` to bundle. `ds-bundle/` is produced by a script, not by `package-build.mjs`; `_ds_bundle.js` is an empty-bodied bundle with the `@ds-bundle` header and `components/` is empty. `_ds_sync.json` is omitted on purpose (no anchor → every sync re-verifies, which is correct here).
- **Token source**: `DpSemanticTokenManifest.cssCustomProperties(Brightness.light|dark)` + `AppTokens.standard` + `dpWindowClassOf` thresholds, dumped by `packages/dp_design/test/theme/dp_semantic_tokens_dump_test.dart` (`DP_TOKEN_DUMP=<path> flutter test …`). The Flutter projection emits package-qualified font families (`"packages/dp_design/Pretendard"`); the build script normalises them to `"Pretendard"` / `"D2Coding"` to match the shipped `@font-face`.
- **Fonts**: woff2 files are the ones the homepage serves (`devpath-home-page/e2e/visual/fonts/manifest.v2.json`, sha256-verified): Pretendard 1.3.9 400/500/600/700, D2Coding 1.3.2 subset. Do not list "Apple SD Gothic Neo" in fallbacks — the validator flags it as a missing font.
- **Guidelines**: only the product contract `DESIGN.md` (repo root). The homepage's `DESIGN.md` uses a different marketing palette and is deliberately excluded.
- **Divergence found (2026-09-17)**: `devpath-home-page/assets/tokens.css` (the landing mirror of contract 1.0.0, synced 2026-08-15) still carries the pre-redesign palette (`--dp-color-primary: #B45309`) and layout widths 1440/880/256/72, while the app (`af1995c`, 2026-09-13 mobile-first redesign) projects `#5653E7` and `AppTokens.standard` 1360/760/280/80 — the contract values changed without a version bump and the homepage contract test pins the old values. Sync source here is the app.
- **Validator**: needs `ds-bundle/components/` to exist even when empty, and `.ds-build-meta.json` with `componentCount: 0` to take the tokens-only branch. Run it from a staged `.ds-sync/` (this repo has no npm root; the homepage worktree's staging was used).
- **Rebuild**: `flutter test` the dump test → `build_ds_bundle.py` → `build_ds_readme.py` (both scripts live in the session scratchpad; copy them into `.design-sync/scripts/` if they need to survive — TODO on the next sync).
