# Font Diet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut the fonts share of the cold web transfer (10.4 MB of 22 MB) without losing any Hangul glyph: subset the five packaged fonts to the Korean web ranges and load D2Coding only when code text is rendered.

**Architecture:** A deterministic fontTools script regenerates the packaged fonts in place (same file names, so every ET13 pin and bootstrap fallback URL keeps its path; only bytes/sha change in `evidence/et13/assets.lock.json` and the tool's `_expectedAssets`). D2Coding moves from `fonts:` (FontManifest, loaded at startup) to `assets:` in `packages/dp_design/pubspec.yaml`, and a new `DpCodeFont.ensureLoaded()` registers it through `FontLoader` the first time a code style is built (DpMarkdown, sandbox, admin).

**Tech Stack:** Flutter 3.44.1 web (CanvasKit), fontTools 4.65.0 (`py -m fontTools.subset`), ET13 evidence tool, tools/perf measurer.

**Spec:** `docs/community-information-architecture/handoff.md` §9.6 item 1 and `docs/design/perf-baseline.md` §해석과 후속 과제 1.

## Global Constraints

- Measured on 2026-09-17: Pretendard variable TTF is 6.7 MB (bigger than the four statics, 6.3 MB); woff2/woff are not readable by CanvasKit → **keep the four static OTFs and D2Coding TTF, subset in place**.
- Never drop a Hangul syllable (U+AC00–D7A3, 11,172) or Jamo: a missing glyph makes CanvasKit fetch Noto fallback from gstatic at runtime, which the ET13/browser-ux/perf sandboxes block.
- Unicode ranges (fixed): `U+0000-00FF,U+0100-017F,U+02B0-02FF,U+0300-036F,U+1100-11FF,U+2000-206F,U+20A0-20CF,U+2100-214F,U+2190-21FF,U+2200-22FF,U+2300-23FF,U+2460-24FF,U+2500-259F,U+25A0-25FF,U+2600-26FF,U+2700-27BF,U+3000-303F,U+3130-318F,U+A960-A97F,U+AC00-D7A3,U+D7B0-D7FF,U+FE00-FE0F,U+FF00-FFEF`.
- Subset must be byte-reproducible (`--no-recalc-timestamp --no-recalc-bounds`, pinned fontTools version) because `assets.lock.json` pins bytes + sha256.
- File names and asset paths do not change (`packages/dp_design/fonts/*.otf|ttf`); bootstrap `fontFallbackBaseUrl` stays `Pretendard-Regular.otf?`.
- ET13 `loadEt13EvidenceAssetFonts` keeps loading D2Coding explicitly (it stays a packaged asset at the same path).

```python
"""Deterministic Korean-web subset of the packaged fonts (N04 follow-up, 2026-09-17).

Usage:
  py tools/fonts/subset_fonts.py --source <dir>           # regenerate packages/dp_design/fonts/*
  py tools/fonts/subset_fonts.py --source <dir> --check   # verify packaged bytes == subset(source)

<dir> holds the upstream originals: Pretendard-{Regular,Medium,SemiBold,Bold}.otf (v1.3.9)
and D2Coding.ttf (1.3.2). Requires fontTools 4.65.0 (pip install fonttools==4.65.0).
Output is byte-reproducible: timestamps/bounds are not recalculated.
"""
import argparse, hashlib, io, sys
from pathlib import Path
from fontTools import version as fonttools_version
from fontTools.subset import Options, Subsetter, load_font, save_font

FONTS = ["Pretendard-Regular.otf", "Pretendard-Medium.otf", "Pretendard-SemiBold.otf", "Pretendard-Bold.otf", "D2Coding.ttf"]
UNICODES = "U+0000-00FF,U+0100-017F,U+02B0-02FF,U+0300-036F,U+1100-11FF,U+2000-206F,U+20A0-20CF,U+2100-214F,U+2190-21FF,U+2200-22FF,U+2300-23FF,U+2460-24FF,U+2500-259F,U+25A0-25FF,U+2600-26FF,U+2700-27BF,U+3000-303F,U+3130-318F,U+A960-A97F,U+AC00-D7A3,U+D7B0-D7FF,U+FE00-FE0F,U+FF00-FFEF"
REQUIRED_FONTTOOLS = "4.65.0"
TARGET = Path(__file__).resolve().parents[2] / "packages" / "dp_design" / "fonts"


def parse_unicodes(spec):
    out = set()
    for part in spec.split(","):
        a, _, b = part.removeprefix("U+").partition("-")
        lo, hi = int(a, 16), int(b or a, 16)
        out.update(range(lo, hi + 1))
    return out


def subset_bytes(source: Path) -> bytes:
    options = Options()
    options.layout_features = ["*"]
    options.name_IDs = ["*"]
    options.notdef_outline = True
    options.glyph_names = True
    options.recalc_timestamp = False
    options.recalc_bounds = False
    options.drop_tables += ["FFTM"]
    font = load_font(str(source), options)
    subsetter = Subsetter(options=options)
    subsetter.populate(unicodes=parse_unicodes(UNICODES))
    subsetter.subset(font)
    buffer = io.BytesIO()
    save_font(font, buffer, options)
    return buffer.getvalue()


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--source", required=True)
    parser.add_argument("--check", action="store_true")
    args = parser.parse_args()
    if fonttools_version != REQUIRED_FONTTOOLS:
        sys.exit(f"fontTools {REQUIRED_FONTTOOLS} required, found {fonttools_version}")
    drift = 0
    for name in FONTS:
        data = subset_bytes(Path(args.source) / name)
        target = TARGET / name
        digest = hashlib.sha256(data).hexdigest()
        if args.check:
            packaged = target.read_bytes()
            ok = packaged == data
            drift += 0 if ok else 1
            print(f"{'OK  ' if ok else 'DRIFT'} {target.as_posix()} {len(packaged)} {hashlib.sha256(packaged).hexdigest()}")
        else:
            target.write_bytes(data)
            print(f"{target.as_posix()} {len(data)} {digest}")
    sys.exit(1 if drift else 0)


if __name__ == "__main__":
    main()
```

```dart
// packages/dp_design/lib/src/theme/dp_code_font.dart
import 'package:flutter/foundation.dart';
import 'package:flutter/services.dart';

import 'dp_typography.dart';

/// D2Coding 지연 로더. FontManifest 에서 빼고(시작 시 2 MB 절감) 코드 스타일이
/// 처음 그려질 때 한 번만 등록한다. 등록 전에는 fallback 폰트로 그려지고,
/// [FontLoader.load] 가 끝나면 Flutter 가 텍스트를 다시 배치한다.
abstract final class DpCodeFont {
  static const String assetPath = 'packages/dp_design/fonts/D2Coding.ttf';
  static Future<void>? _loading;
  static bool _loaded = false;

  static bool get isLoaded => _loaded;

  static Future<void> ensureLoaded() => _loading ??= _load();

  static Future<void> _load() async {
    try {
      final loader = FontLoader(DpTypography.codeFamily)
        ..addFont(rootBundle.load(assetPath));
      await loader.load();
      _loaded = true;
    } catch (error) {
      _loading = null; // 다음 호출이 다시 시도한다.
      rethrow;
    }
  }

  @visibleForTesting
  static void resetForTest() {
    _loading = null;
    _loaded = false;
  }
}
```
