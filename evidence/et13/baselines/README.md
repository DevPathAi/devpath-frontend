# ET13 baseline boundary

The fixture catalog is approved, but no visual baseline or assistive-technology
review is approved yet. The committed state therefore remains
`pending_external_review`.

CI captures production-distribution candidates and may compare an externally
approved baseline bundle. CI cannot create, replace, or approve baselines. The
external updater refuses to run when `CI` is set and requires a separately
reviewed approval manifest whose catalog, source, and candidate hashes match.
